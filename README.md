## Overview

This repository contains the source code of my personal portfolio, a fast, responsive, single-page site built with Next.js and Tailwind CSS. It presents my background as a BS Data Science student at UET Lahore, my technical skills, selected projects, certifications, and ways to get in touch.

**Live:** [haroon-khurram.vercel.app](https://haroon-khurram.vercel.app)

## Features

- **Responsive design** that works across mobile, tablet, and desktop
- **Light / dark theme toggle**
- **Sectioned single-page layout:** Home, About, Skills, Projects, Certifications, Contact
- **Project showcase** with screenshots, tech stacks, key areas, and links to source code
- **Verified certifications** with links to credentials
- **Downloadable résumé** (PDF)
- **Contact section** with a message form, email copy button, and social links
- **SEO-ready:** page metadata, Open Graph, and Twitter card images
- **Optimized fonts and images** via `next/font` and `next/image`

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org) 20 or later
- npm (included with Node.js), or yarn / pnpm / bun

### Installation

```bash
# Clone the repository
git clone https://github.com/HaroonKhurram/portfolio.git

# Move into the project directory
cd portfolio

# Install dependencies
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. The page reloads automatically as you edit files.

### Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create an optimized production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint across the project |

## Deployment

The site is deployed on [Vercel](https://vercel.com). To deploy your own copy:

1. Fork or clone this repository.
2. Import the project into Vercel.
3. Vercel detects Next.js automatically; click **Deploy**.

Every push to `main` triggers a new production deployment.

## Customization

To adapt this portfolio for your own use:

1. Replace the personal details, project data, and certifications in `src/`.
2. Swap the images and résumé PDF in `public/`.
3. Update the page metadata (title, description, Open Graph) to match your own.
